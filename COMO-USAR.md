# COMO USAR

1. Siga os passos do arquivo `COMO-INSTALAR.md`
2. No arquivo `TEXT.txt` coloque o texto que quiser e salve
3. Clique no arquivo `.bat` com o nome da voz que você quiser
4. Você pode usar os IDs e nomes das vozes em `voices.txt` para criar seus próprios arquivos `.bat` com as vozes em outras línguas.

Os áudios gerados ficarão na pasta `outputs/`.
